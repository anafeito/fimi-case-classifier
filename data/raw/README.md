Place the Kaggle export here (not committed to git):

1. Download https://www.kaggle.com/datasets/imuhammad/euvsdisinfo-disinformation-database
2. Unzip so that `data/raw/euvsdisinfo_v1_2.csv` exists (tab-separated, 9,075 rows, 2015-2020).

Or with the Kaggle CLI:

    kaggle datasets download -d imuhammad/euvsdisinfo-disinformation-database -p data/raw --unzip
